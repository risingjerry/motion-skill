# Security / 安全

The scripts in this repository run only on your machine. They do not go online and do not handle accounts or keys.

If you find a security issue (for example, a script that executes untrusted input or writes files somewhere unexpected), please report it privately through [GitHub private vulnerability reporting](https://github.com/risingjerry/motion-skill/security/advisories/new) instead of opening a public issue. Only the latest version is maintained.

这个仓库的脚本只在本机运行，不联网、不处理账号或密钥。
如果发现安全问题（例如脚本会执行不受信任的输入、或会把文件写到意料之外的位置），请通过上面的 GitHub 私密漏洞报告提交，不要公开提 Issue。只维护最新版本。
