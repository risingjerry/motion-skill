# 声音：画面定了最后加

画面每改一次，节拍都会挪。所以先把画面定稿，再做声音。
没有声音的动效广告看起来像半成品；配乐和音效都要有。

## 三样东西

| | 作用 | 对齐方式 |
|---|---|---|
| 配乐 | 给整条片子定情绪和节奏 | **最重的一拍对准画面的关键落点**（通常是结尾图标落定那一刻） |
| 音效 | 让每个动作“有分量” | 嗖声（whoosh）对准动作最快的那一刻（`align: peak`）；点击、落定、弹出对准起音（`align: onset`） |
| 配音（可选） | 讲产品 | 原声一个采样都不改，只整体平移 |

## 流程

```bash
# 1. 出片时已经写了节拍表：片名-4K.beats.json（来自页面的 BEATS）
# 2. 没有配乐素材时，用代码合成一套（免版权，MIT）
python3 scripts/audio/synth.py kit audio/sfx
python3 scripts/audio/synth.py bed audio/bed.wav --duration 14 --hit 9.0
# 3. 写 sound.json，混音并合进成片
python3 scripts/audio/mix.py sound.json mix.wav --video 片名-4K.mp4 --out-video 片名-4K-有声.mp4
```

`sound.json` 的格式见 `scripts/audio/mix.py` 开头，例子见 `examples/minimal/sound.json`。
时间可以写秒数，也可以写 `"beat:lockup"`、`"beat:flip+0.75"`，直接引用页面里的节拍名。

## 规矩

- **配乐只平移、裁剪，不变速、不变调。** 找到配乐里最重的一拍（`hit_in_file: "auto"` 自动找低频能量跳得最猛的一刻，或手动写秒数），
  整首平移到让它落在画面落点上。配乐可以从中间开始（脚本会算出“配乐第几秒对应片子第 0 秒”）。
- **最重的一拍前面留一口气。** 好的配乐在落点前会收一下（少一拍鼓、或只剩铺底），落点才砸得响。挑配乐时找这种结构。
- **音效响时配乐让路。** `duck` 按音效包络压低配乐（默认 4–5 dB，10 ms 压下、约 0.3 s 回来），音效不会被盖住。
- **不是每个动作都要声音。** 很安静的开头、匀速没有落点的段落，不加反而干净。
- **整体响度 -14 LUFS，真峰值 ≤ -1 dBTP。** 这是多数视频平台的标准，太响会被平台压，太轻会被划走。脚本会测并迭代到位。
- **视频流原样拷贝。** 合声音时不重新编码画面（`-c:v copy`），画质不损失，帧也不会错位。
- **音画只整体平移。** 要整体提前或推后就改 `offset`，不拉伸、不变速。

## 自查（交付前）

- 读 `mix.py` 打印的报告：配乐最重一拍在片子第几秒、每个音效的时间、最终 LUFS 和真峰值。
- 抽查：在关键落点前后各抽一帧看画面，对照报告里的时间。
- 如实告诉对方：时间点是按画面代码和节拍表对的，响度是测出来的，但**没有真人试听过**，请对方戴耳机听一遍再定。
