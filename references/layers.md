# 三层：做到哪一步

三层共用同一套流程（备料 → 分镜 → 搭页面/场景 → 逐帧自查 → 4K → 声音）。区别只在“画面从哪来”。
一条片子可以混用：开头用第 3 层的产品特写，中间用第 1 层的界面动效，结尾剪影转场接实拍。

## 第 1 层：平面动效（HTML）

- **画面：** 真 logo（SVG 最好）、品牌色、真截图、几何形状。一个形状一路变形下去：点 → 圆 → 图标 → 卡片 → 图标 + 字标。
- **工具：** `templates/2d.html` + `templates/motion-kit.js`，`scripts/render.mjs` 出片。
- **速度：** 10 秒 4K 大约 2–4 分钟出片，改一个节拍重渲一次也是这个时间。
- **适合：** App、SaaS、品牌开场、数据卡片。
- **注意：** 字体用系统里有的或随项目带的字体文件；截图先去掉通知角标、头像、手机号、真实姓名。

## 第 2 层：浏览器 3D + 接实拍

- **画面：** 界面卡片（真截图）摆在三维空间，镜头沿一条连续路线穿过；离焦的卡片自动变糊，像真镜头的景深。
- **工具：** `templates/3d.html`（CSS 3D 变换，不需要显卡，无头浏览器里稳定）。需要真实模型时可以自己接 three.js 等 WebGL 库，出片加 `--gpu`。
- **接实拍：** `scripts/silhouette.py` 把实拍的人变成干净剪影，从局部特写拉开，再硬切回实拍。见 `silhouette.md`。
- **适合：** 多屏界面巡游、要和真人出镜片段接起来的片子。

## 第 3 层：Blender 棚拍

- **画面：** 实物产品的 3D 模型，一盏面光，黑背景，真实的反光和阴影。
- **工具：** `scripts/blender/studio.py`（后台运行，不用打开 Blender 界面），检查用 `motion_check.py` 和 `seam_check.py`。
- **模型从哪来：** 厂商公开的 AR/3D 文件、对方自己的 CAD 导出、或按实物照片用代码建模。先确认授权允许这样用。
- **速度：** EEVEE 4K 64 采样大约每帧几秒到十几秒（看机器），一条 15 秒片子可能要一小时。先用 960x540、8 采样出预览，节奏定了再出 4K。
- **适合：** 耳机、手机、杯子、包装盒这类实物。

## 怎么选

| 问题 | 选 |
|---|---|
| 产品是软件、没有实物 | 第 1 层，多屏展示再加第 2 层 |
| 产品是实物，有模型或能建模 | 第 3 层做主体，字和结尾用第 1 层 |
| 片子要接真人实拍 | 加第 2 层的剪影转场 |
| 时间很紧 | 第 1 层；第 3 层最慢 |
