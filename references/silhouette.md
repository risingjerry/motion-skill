# 剪影转场：从 3D/动效接到实拍

效果：动效里的主体（比如一只耳机）飞向画面某一点 → 画面变成纯色背景上的人物剪影 → 剪影从局部特写拉开 → 硬切回彩色实拍。
它把“做出来的画面”和“拍出来的画面”缝在一起，看起来像一个连续镜头。

## 步骤

1. **从实拍里拆帧**（4K 源，帧率和成片一致）：
   ```bash
   ffmpeg -i 实拍.mp4 -ss 4.0 -t 2.0 -vf fps=30 frames/%04d.png
   ```
2. **抠人，得到黑白蒙版**（白=人）：
   ```bash
   python3 scripts/silhouette.py mask frames masks
   ```
   - macOS 14+ 用系统自带的 Vision（`scripts/silhouette/vision_mask.swift`），不用装别的；第一次运行要编译，稍慢。
   - 其他系统：用 rembg（`pip install rembg`，`rembg p -om frames masks`）、MediaPipe Selfie Segmentation、
     达芬奇 Magic Mask、After Effects Roto Brush、剪映智能抠像，导出黑白蒙版序列即可。
3. **画剪影**：
   ```bash
   python3 scripts/silhouette.py draw masks sil --size 3840x2160 \
       --crop-start 0.45,0.20,0.18,0.18 --crop-end 0,0,1,1 --fg 0,0,0 --bg 255,255,255
   ```
   - `--crop-start` 是开头的取景框（x, y, 宽, 高，占原画面的比例）：**从局部特写开始**，例如耳朵、手、产品被握住的地方；
     `--crop-end 0,0,1,1` 拉到全画面。中间按平滑曲线过渡。
   - 剪影是矢量轮廓按取景框重新画的，特写放大也没有锯齿。
4. **接起来：** 剪影帧后面硬切实拍的同一帧（同一取景），不要叠化。

## 让剪影干净

- `--temporal 1`：前后各 1 帧的蒙版取平均，去掉边缘闪烁。人几乎不动时可以加到 2。
- `--sigma`（默认 6，按 1920 宽计）：越大轮廓越圆润、细节（发丝、镜腿）越少。
- `--smooth`（默认 10 点）：沿轮廓平滑，去掉小锯齿。
- 自动只留最大的一块（去掉背景里被误认的东西），并补上小洞（镜片缝、指缝）。
- 抠像软件偶尔把椅背、桌角并进人里：先看蒙版序列，有问题的几帧用干净帧的蒙版替换或手动擦掉。

## 设计要点

- 剪影段别太长（1–1.5 秒），它是过渡，不是主体。
- 从特写开始比从全身开始好看：全身小剪影显得廉价，特写的轮廓线条才有设计感。
- 动效主体最后停下的位置，要和实拍里对应物的位置、大小、朝向对上（例如耳机柄尖对到实拍耳朵里的柄尖）。先在实拍帧上量好坐标，再反推 3D 相机。
- 剪影和背景颜色用片子的主色，黑白最稳。
