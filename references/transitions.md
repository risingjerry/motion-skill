# 镜头怎么接：每一镜从上一镜变出来

## 核心规矩

**不用淡入淡出、不用叠化（交叉溶解，cross-dissolve）、不用“切到下一页”。** 下一镜的主角，要由上一镜画面里已经有的东西变出来。
观众的眼睛一直盯着同一个位置、同一个东西，所以不会走神。叠化是最容易偷懒的接法：前一镜淡出、后一镜淡入，一看就廉价。

做分镜时对每两镜之间问一句：“这个形状怎么变成那个形状？”写进分镜的“怎么变成下一镜”一栏。
对方说不出想要哪种变法时，不要自己随便挑一种：同一处给 2–3 个变法（各一句话 + 一张静帧），让对方选。

## 常用的变法

| 变法 | 例子 | 实现 |
|---|---|---|
| 长大 / 收缩 | 一个点长成硬币 | 宽高从小到大，同一个元素 |
| 改形状 | 圆 → 圆角方 → 长方形卡片 | 宽、高、圆角放进同一条连续轨道 |
| 翻面 | 硬币翻过去是 App 图标 | 父元素 `rotateY` 0→180°，正反两面 `backface-visibility: hidden` |
| 展开 | 图标长成手机屏、界面浮现 | 尺寸变化，内容在后半段浮现 |
| 收回 | 手机屏收回成图标 | 展开的反过程 |
| 推进去 | 镜头推进界面里的一个按钮，按钮变成下一镜的背景 | 整个世界放大，目标始终在画面正中 |
| 让位 | 图标往左挪，字标从右边出现 | 字标贴着图标走，整组居中 |
| 剪影 | 3D 物体变成纯色剪影，剪影里出现实拍人物的轮廓 | 见 `silhouette.md` |

## 让动作看起来顺

- **一个动作一条曲线。** 位置、大小、角度都用一条从头到尾的缓动曲线。把两段路径拼起来，接头处会有一下顿挫。
- **方向不回头。** 不要推近又拉远、放大又缩小、转过去又转回来。
- **快起慢收。** 动作开始快一点，结束慢下来，慢的那段要够长（例如 1 秒的动作，后 0.6 秒都在减速）。第一版几乎都太快，宁可多留时间。
- **形状保持形状。** 变形过程中曲线不要突然翻转；一起动的几样东西保持间距和速度一致。
- **主角在正中。** 变形时以画面中心为原点，不要让主角跑到角落。
- **一直在动。** 整个世界加一个全程匀速的慢推（例如 10 秒放大 8%），停住的镜头也不会显得死。
- **转速不跳。** 翻转、旋转的角速度要连续，峰值每帧不超过约 6°（30 fps）。

## 文字

- 短：一句话，中文 10 字以内最好。
- 出现方式（默认）：**逐词往上滑到位**（`slideUp()`）。一个词接一个词从下面滑上来、到位就停，像被一扇看不见的窗口露出来。
  这是现在高级片最常用的出字方式。中文会自动按词拆；想自己定怎么断，就在字里加空格（“想看的 刷一下 就有”）。
- 也可以用 `reveal()`：逐字从模糊、略低、透明变成清楚。适合很短的字标。
- 不要：弹跳、缩放出现、打字机光标、一个字一个字地淡入淡出。
- 位置：放在主体旁边，和主体外框至少隔 40 像素（4K）。用 `layout_check.py` 量，不靠目测。
- 消失：比出现更快，同样从清楚变模糊。

## 电影感：景深

要“像真摄影机拍的”，就让背景虚掉：对焦在主角上，前后的东西按离焦距离变糊。
`templates/3d.html` 已经按每块屏离对焦距离自动加模糊；平面片子也可以给背景层加 `filter: blur()`，主角保持清楚。
虚化要克制：主角和字永远是清楚的，糊的只是陪衬。Blender 里近拍时景深很浅，见 `blender-3d.md`。

## 看着“土”的东西

做完对照这张表过一遍，有就改：

- 直角方块卡片、切到画面边缘的纯黑板、底部黑横条 → 改成大圆角、留边距的卡片，“圆润”比“方正”高级。
- logo 外面套虚线框、描边框；抠图后边缘有白边或锯齿的 logo → 用原始 SVG / 透明 PNG，不描框。
- 画面上的药丸标签、编号圆圈、“第 1 步”小牌 → 分镜里可以有编号，成片里不要。
- 把丑素材（翻车版、灰模、低清截图）铺满全屏当主角 → 只当小配角，或者不用。
- 只用一种转场、一种出字方式贯穿全片还好；但只用一种音效就会乏味，见 `sound.md`。

## 结尾

只留图标和字标（或者硬切到实拍）。不加“立即下载”“打开 XX”“扫码”之类的口号；
画面里不放“概念片，非官方”这类小字——需要说明就写在发布简介里或口播里。
