# 分镜：先给人看，点头再做

分镜是整条片子里最便宜的修改点：还没渲染任何东西，改一句话就是改一个镜头。
带编号是为了让对方能精确地说“3 变 4 那里太快”，而不是“中间有点怪”。

## 每个镜头写什么

| 字段 | 含义 | 例子 |
|---|---|---|
| `id` | 编号，从 1 开始 | 3 |
| `from` / `to` | 时间段（秒） | 2.9 / 4.2 |
| `at` | 分镜板上截哪一刻的画面（有页面时） | 3.7 |
| `picture` | 画面里有什么 | App 图标长成手机屏 |
| `move` | 这一镜里什么在动、怎么动 | 图标原地拉高拉宽，界面浮现 |
| `into_next` | 怎么变成下一镜（不许写“淡出”） | 屏幕里逐行出现账目 |
| `line` | 屏幕上的字（可选） | 每一笔，都记得 |
| `image` | 用现成图当这一格画面（可选，路径相对 json） | sketches/03.png |

完整例子：`examples/minimal/shots.json`。

## 出分镜板

```bash
node scripts/render.mjs board shots.json board.png
```

- 有 `page`（HTML 动画）时，每格自动截 `at` 那一刻的真实画面。
- 还没写页面时，不写 `page`，格子里显示文字草图；也可以给每格配一张 `image`（手绘、Blender 低清静帧都行）。
- 第 3 层可以先用 `studio.py --res 960x540 --samples 8 --frames 1,30,60` 渲几张低清静帧当分镜画面。

## 写分镜时自问

1. 每一镜的 `into_next` 是不是“同一个东西变成下一个东西”？如果写的是“切到”“淡入”，重想。
2. 主角是不是一直在画面中间附近？
3. 有没有哪一镜是完全静止的？加一点慢推。
4. 结尾是不是只有图标和字标？
5. 每句字是不是一眼能读完（中文 10 个字以内最好）？
6. 实物镜头的比例、开合方式，和对方给的实物照片一致吗？

## 等对方回复

把 `board.png` 发给对方，明确说“看过点头我再做成片”。对方提了意见就改 `shots.json` 重新出图，编号跟着镜头走，不重排。
