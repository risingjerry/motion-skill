# 检查清单

“我看过了”不算检查。每一项要么有脚本输出，要么有抽帧图。

## 分镜阶段（给对方看之前）

- [ ] 5–10 个镜头，每个都有编号、时间段、画面、动作、怎么变成下一镜
- [ ] 没有一镜写着“淡入/淡出/切到”
- [ ] 结尾只有图标和字标，没有口号、没有免责小字
- [ ] 用的都是真素材：官方 logo、真机截图（已去掉个人信息），不是商店宣传图
- [ ] 实物产品：有实物照片做对照

## 成片前（自查，渲 4K 之前）

- [ ] 每个转场抽 3–4 帧（开始、中间两点、结束），拼成检查图看过：`render.mjs still` + `sheet.py images`
- [ ] 主体在画面正中附近：`layout_check.py probe --center <主体>`
- [ ] 文字离主体 ≥ 40 px（4K）：`layout_check.py probe`（HTML）或 `layout_check.py mask`（3D 透明底）
- [ ] 没有完全静止的帧（至少有慢推）
- [ ] 没有方向回头的动作（推了又拉、转了又回）
- [ ] 3D：`motion_check.py` 绿（不穿模、≤ 6°/帧、转速不跳）
- [ ] 3D 合盖：`seam_check.py` 绿（≤ 1 px @4K）
- [ ] 3D：和实物照片同角度对照过比例
- [ ] 3D：只有一盏灯

## 成片后

- [ ] 分辨率 3840x2160：`ffprobe -v error -show_entries stream=width,height -of csv=p=0 成片.mp4`
- [ ] 从 4K 成片里抽帧看（不是从预览里）：`sheet.py video 检查.jpg 成片.mp4 --times ... --save-frames 帧目录`
- [ ] 4K 原尺寸看细节：边缘锯齿、文字清晰度、截图里有没有漏掉的个人信息
- [ ] 声音：`mix.py` 报告里 -14 LUFS（±0.5）、真峰值 ≤ -1 dBTP
- [ ] 声音：配乐最重一拍的时间 = 关键落点的时间
- [ ] 合声音时视频流是原样拷贝的（报告里有 `-c:v copy`，文件大小和画面没变）

## 交付时说清楚

- 改了什么（按分镜编号说）
- 查过什么（贴脚本输出的结论行，例如 `LAYOUT_CHECK GREEN`）
- 没查到的（例如“没有真人试听过混音”“只看了静帧没看连续播放”）
