# 踩过的坑

按症状查。每条写了原因和改法。

## 画面

| 症状 | 原因 | 改法 |
|---|---|---|
| 浏览器里预览正常，成片动作不对 | 动画靠 `setTimeout` / CSS transition / 自己的 requestAnimationFrame 推进 | 所有状态都由 `seek(t)` 算出来；CSS 动画用 `@keyframes`（渲染时会被拨到 t） |
| 成片里中文是方块或字体不对 | 系统里没有指定字体 | 字体栈里放几种常见中文字体；或把字体文件放进项目用 `@font-face` 引用 |
| 文字被物体挡住 | 物体运动轨迹没算进去，只看了停住的画面 | 每帧量：`probe` + `layout_check.py`；字贴着主体走，或者等主体让开再出字 |
| 字标出现时压到正在挪动的图标 | 字标位置按“图标最终位置”算的，图标还没到 | 字标位置跟着图标当前位置算 |
| 看不见的字被检查报红 | 字的容器透明度是 1，只有每个字的 span 是 0 | 用 `reveal()`（会自动隐藏容器），或自己在没出现时设 `visibility:hidden` |
| 4K 渲染时电脑卡死 | 同时跑了多个 4K 渲染或 Blender | 一次只跑一个重任务 |
| `--scale 0.5` 出来还是 1080p | Chrome 截图不支持小于 1 的缩放 | 预览用 `--scale 1`；要更小就把页面尺寸改小 |
| 画面看着“死” | 有停住不动的镜头 | 整个世界加全程匀速慢推 |
| 动作有一下顿挫 | 两段路径拼接，接头处速度不连续 | 一个动作用一条曲线；镜头参数都由同一个进度驱动 |

## 3D

| 症状 | 原因 | 改法 |
|---|---|---|
| 盖子合不上、一边台阶一边凸出 | 模型自带的转轴不在真实铰链上 | 按盖子口沿和盒身口沿对齐来算铰链位置；`seam_check.py` 量到 ≤ 1 px |
| 模型大小差 1000 倍 | 文件单位是毫米、场景是米（或反过来） | 看 `studio.py` 打印的物体尺寸，和实物规格对一下再缩放 |
| 快动作出现一节一节的残影 | EEVEE 运动模糊子步数太少 | `--motion-blur 16` 或更多 |
| 产品看起来像塑料玩具 | 灯太多、太平；或材质太粗糙 | 只留一盏灯；白塑料粗糙度 0.2–0.3 加清漆 |
| 一半画面是糊的 | 近拍景深太浅 | 不开景深，或光圈收到 f/11–16 |
| 两个物体交换位置时互相穿过 | 位置直线插值 | 绕两者中点公转半圈，一个走前一个走后，留出间隙 |
| 物体升出盒子时报穿模 | 模型没建内腔 | 属于合理接触，检查报告里写明帧范围，不要硬改动画 |
| 剪影边缘发虚 | 用了带运动模糊的通道做剪影 | 剪影用的通道关掉运动模糊 |
| 剪影边缘闪 | 每帧蒙版单独算 | `--temporal 1` 或 2 |
| 抠像把椅子也算进人 | 人静止时抠像模型分不清 | 用干净帧的蒙版替换那几帧，或手动擦掉 |

## 声音

| 症状 | 原因 | 改法 |
|---|---|---|
| 配乐高潮和画面落点差半拍 | 改了画面后没重新对 | 画面定稿后再做声音；节拍从 `beats.json` 读，不手抄 |
| 音效被配乐盖住 | 没让路 | `duck.depth_db` 4–6 |
| 平台上播放声音忽大忽小 | 没做响度归一化 | -14 LUFS、真峰值 ≤ -1 dBTP |
| 声音和画面慢慢错开 | 变了速或帧率不一致 | 只整体平移；声音按视频时长裁齐 |

## 流程

| 症状 | 原因 | 改法 |
|---|---|---|
| 做完才发现方向不对，返工一整天 | 没等分镜点头 | 分镜板发出去，对方点头再做 |
| 临时目录里认可过的成品没了 | 临时目录重启会清空 | 认可的版本立刻存到项目文件夹 |
| 说“检查过了”结果有错 | 只看了停住的画面 | 每个转场抽 3–4 帧；用脚本量，不靠目测 |
